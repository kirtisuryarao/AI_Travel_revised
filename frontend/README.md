# TravelAI Frontend

Next.js UI for the AI Travel Planner. The browser talks only to the API Gateway at `http://localhost:8080`.

```text
Node.js
Next.js 14
```

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Flow: trip form (including Maximum Hotel Budget Per Night) → flight cards → hotel cards → AI itinerary → save trip.
